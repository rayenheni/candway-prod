## 1. Product Vision

### What is Candway?

Candway is an AI-powered recruitment platform that automates candidate screening, conducts intelligent video interviews, and provides data-driven hiring recommendations—all while reducing bias and improving hiring velocity.

### What Problem Does It Solve?

| Traditional Hiring Pain Point | Candway Solution | Business Impact |
|---|---|---|
| **40+ hours per hire** on CV screening | AI screens 1000+ CVs in seconds | 10x faster initial screening |
| **$4,000+ cost-per-hire** from manual processes | Automated scoring reduces recruiter time | 60% cost reduction |
| **Unconscious bias** in human evaluation | Standardized AI rubric scoring | 40% improvement in diversity metrics |
| **Poor candidate experience** with radio silence | Real-time feedback and scores | 85% candidate satisfaction |
| **Inconsistent evaluation criteria** across hiring teams | Configurable rubrics + calibration | Standardized hiring decisions |

### Why Now?

- **AI adoption is mainstream** (ChatGPT reached 100M users in 2 months)
- **Remote hiring exploded** — 73% of companies now hire remote-first
- **Talent shortage crisis** — 3x more jobs than qualified candidates in tech
- **Regulatory pressure** on hiring bias (EU AI Act, NYC Local Law 144)
- **SMBs need enterprise-grade tools** without enterprise complexity

### Mission

> **Democratize AI recruitment for SMEs worldwide**

Enable small and medium businesses to compete for top talent with enterprise-grade AI hiring capabilities.

### Long-Term Vision

1. **Phase 1:** AI Hiring Assistant (current)
2. **Phase 2:** Talent Intelligence Platform (predictive hiring)
3. **Phase 3:** Autonomous Hiring Agents (end-to-end automation)
4. **Phase 4:** Global Talent Graph (network effects)

### Unique Value Proposition

> **"Hire better candidates 10x faster with AI that explains every decision."**

- **Explainable AI:** Every score includes evidence and reasoning
- **Bias-reduced hiring:** Standardized rubrics across all evaluations
- **Zero-setup automation:** From job post to shortlist in 15 minutes
- **Candidate-first experience:** Real-time feedback, no ghosting

### C) Skill Tree System

#### Purpose

The Skill Tree System provides a standardized competency framework for technical roles, enabling consistent evaluation across different candidates, positions, and time periods.

#### How Companies Use It

- **Define role requirements:** Map job responsibilities to specific skills
- **Calibrate scoring:** Adjust weightings for different competencies
- **Benchmark candidates:** Compare against industry-standard skill frameworks
- **Close skill gaps:** Identify training priorities for team development

#### How Candidates Are Evaluated

1. **CV Analysis:** Skills extracted from resume text
2. **Interview Performance:** Skills validated through Q&A
3. **Skill Score:** Combined score (0-100) per skill
4. **Delta Score:** Gap between claimed and demonstrated skills

#### Competitive Advantage

- **Reduced mis-hires:** Clear skill expectations prevent role misalignment
- **Faster ramp-up:** New hires know exactly what skills to develop
- **Better matching:** Skills → Learning recommendations
- **Market differentiation:** First platform to gamify skill validation

## 5. User Workflows

### Recruiter Workflow

```mermaid
flowchart LR
    A[Signup] --> B[Create Company]
    B --> C[Post Job]
    C --> D[Receive Applications]
    D --> E[AI Evaluation]
    E --> F[Review Shortlist]
    F --> G[Make Decision]
    G --> H[Send Offer / Reject]
```

| Step | Actions | Time | Tools Used |
|---|---|---|---|
| **1. Signup** | Email/password, create company profile | 2 min | Auth API, Company CRUD |
| **2. Post Job** | Enter title, description, skills (AI-assisted) | 3 min | Job creation, JD generation |
| **3. Receive Applications** | Email invites sent, inbound applications | Ongoing | Campaign system, apply API |
| **4. AI Evaluation** | CV analysis, match scoring, interview completion | Automated | CV engine, scoring engine |
| **5. Review Shortlist** | Filter by score, view candidate profiles | 10 min per shortlist | Candidate list, profile view |
| **6. Decision** | Compare top 3, adjust weights, request interview | 5 min per candidate | Ranking, pipeline |
| **7. Offer/Reject** | Move to stage, send notification | 1 min per candidate | Pipeline, email system |

### Candidate Workflow

```mermaid
flowchart LR
    A[Apply] --> B[Profile Creation]
    B --> C[CV Upload]
    C --> D[AI Analysis]
    D --> E[AI Interview]
    E --> F[Score & Feedback]
    F --> G[Recruiter Review]
```

| Step | Actions | Time | Tools Used |
|---|---|---|---|
| **1. Apply** | Upload CV or link LinkedIn | 1 min | Apply API, CV parsing |
| **2. Profile Creation** | Edit auto-populated details | 3 min | Profile API |
| **3. CV Analysis** | AI extracts skills, generates summary | 5-10 min (async) | CV analysis service |
| **4. AI Interview** | Complete 5-7 questions | 15-20 min | Interview engine |
| **5. Score** | Receive competency scores + feedback | Immediate | Evaluation results |
| **6. Recruiter Review** | Wait for recruiter action | Variable | Notification system |
